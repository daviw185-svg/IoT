 - A IoT (Internet of Things) é a integração de dispositivos conectados a internet, permitindo coletar dados de um ambiente e suas condições e, mostrar em números e classificações, dependendo de como foi desenvolvido o sistema. 

- Para possuir essa comunicação dos dados, sendo essa necessária e intríseca função, os dispositivos, sendo eles sensores, sejam de umidade, temperatura, batimentos, movimento, etc.) coletam as informações de forma contínua ou sob demanda.

- A transmissão desses dados exige protocolos especializados operando em diferentes camadas, como a conexão e interligação dos equipamentos, seja por meio de Bluetooth, Wi-Fi, redes móveis, ou protocolos de longa distância e baixo consumo como LoRaWAN e Zigbee.
  
- Além disso é necessário utilizar alguma linguagem para enviar e receber as informações. As linguagens MQTT e CoAP são os mais comuns para esses serviços

- Os dados coletados passam por um fluxo de processamento, com o pré-processamento feito próximo ao senhor ou do gateway para economizar banda de rede e responder mais rapidamente a incidentes. Assim, os dados são enviados a servidores locais ou a uma núvem pública (como a AWS, por exemplo) onde os dados são sincronizados e armazenados.  Nesse momento, correlacionam-se dados de diferentes fontes. Algoritmos de Inteligência Artificial e Machine Learning analisam os grandes volumes de dados (Big Data) para identificar padrões, otimizar processos operacionais e automatizar decisões sem intervenção humana.
